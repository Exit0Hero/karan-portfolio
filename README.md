# Karan's Portfolio

A Next.js portfolio showcasing case studies in AI/ML, cybersecurity, and full-stack development.

## Case Studies

Each case study follows the standardized three-beat structure for maximum clarity and impact:

1. **Beat 1: The Problem** - Identifies the real-world challenge and constraints
2. **Beat 2: What I Did** - Details engineering decisions, architecture, and implementation
3. **Beat 3: What Came of It** - Highlights measurable outcomes and performance metrics

### Published Case Studies

- [Project SENTINEL: AI-Based Network Attack Forecasting](./case-studies/project-sentinel.md) - Temporal Graph Neural Networks for predicting network attack trajectories

## Getting Started

First, run the development server:

```bash

# or

# or
```
